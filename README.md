# 減肥大賽計分器

雙軌權重制（體重 40%＋體脂 60%）的減肥大賽計分網頁。輸入初始與結算的體重、體脂率，算出降幅、兩項得分、總分與裁判評語，並可一鍵複製成績單。

**線上使用**：https://badbadted.github.io/weight-loss-score/

## 計分規則

1. 體重得分＝（初始體重－結算體重）÷ 初始體重 × 100 × 0.4
2. 體脂得分＝（初始體脂率－結算體脂率）÷ 初始體脂率 × 100 × 0.6
3. 總得分＝體重得分＋體脂得分

百分比與分數四捨五入到小數點後兩位（半數進位）。總分用未四捨五入的兩項得分相加後再四捨五入，所以偶爾會和「兩項四捨五入後再相加」差 0.01。體重或體脂上升時，該項得分為負。

## 範例

初始 80.0 kg、30.0%，結算 75.0 kg、27.0%：

```
1. 減重數據摘要
   - 體重共減少：5.00 kg（降幅：6.25%）
   - 體脂共減少：3.00 個百分點（降幅：10.00%）

2. 得分試算
   - 體重得分（佔 40%）：2.50 分
   - 體脂得分（佔 60%）：6.00 分

3. 本次比賽最終總得分：8.50 分
```

## 檔案

- `index.html`：計分網頁，所有計算都在瀏覽器裡完成，不會上傳任何數據
- `score.js`：計分邏輯，網頁與 Node 共用
- `test/score.test.js`：測試，執行 `node --test`
